# خبر ماهور 🌾

**دفتر فنی مهندسی و مشاوره کشاورزی ماهور**  
زیر نظر مهندس افشین دهقان

پورتال محلی منطقه بابامنیر و ماهورمیلاتی شامل:
- اطلاع‌رسانی و تبلیغات رسمی و کسب‌وکارها
- صندوق خیریه و اهدای لوازم
- کاریابی محلی
- هواشناسی و توصیه‌های فنی کشاورزی
- معرفی دفتر فنی

## اجرا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## استقرار روی Streamlit Cloud
1. مخزن را در گیت‌هاب بسازید
2. فایل‌ها را آپلود کنید
3. در Streamlit Cloud اپ جدید بسازید و به این مخزن وصل کنید
